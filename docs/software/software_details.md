## 1. Overview
`#Overview` `#Purpose`

PNKAstro is a precision astrology software suite designed for professional astrologers and serious students. It focuses on mathematically exact chart generation, Panchangam data, KP/Lagna motion tables, numerology, and utility tools such as digital Tarot decks. The product UI includes multilingual (Tamil / English) presentation and is intended as a calculation-first tool (not an automated prediction engine).

## 3. Key Features
`#Features` `#Modules`

- **Jamakol Prasannam** — Instant, exact Jamakol chart generation with Udhayam, Aarudam, and Kavippu positions.
- **Birth Horoscope (Natal Chart)** — Fast, high-precision natal chart creation with exact planetary degrees and house divisions.
- **KP Lagna Motion Table** — Detailed KP-style Lagna motion tables showing Lagna movement across Nakshatras, Star Lords, and Sub-Lords; useful for horary and Muhurta.
- **Advanced Numerology Grid** — Instant name-number, birth-number and destiny-number calculations (traditional systems supported).
- **Dynamic Panchangam** — Accurate Tithi, Vara, Nakshatra, Yoga, Karana and related daily almanac data.
- **Advanced Panchangam Search** — Scans multi-decade data ranges to find exact date/time matches, including multi-element (up to 3) overlaps and rare triple-overlaps.
- **Real-Time Hora** — Live calculation of the current planetary hour for timing and Muhurta.
- **Thara / Nakshatra Compatibility** — Daily Nakshatra compatibility and Thara strength computations.
- **Planetary Significators (Karakam Reference)** — Structured reference lists of planetary significations and traits for interpretation support.
- **Digital Tarot Decks** — Simple, randomized digital Tarot interface to support card readings.

## 4. Localization & Calculation Standards
`#Localization` `#Standards`

- **Geographic Anchor:** Chennai (default); supports timezone transformations for other locations.
- **Timezone:** IST (UTC +05:30) by default.
- **Calculation Focus:** Astronomical/astral accuracy prioritized — output intended for human interpretation rather than automated, deterministic predictions.

## 5. Implementation Notes
`#Implementation` `#Frontend`

The product includes a web-based presentation layer (HTML/CSS) with bilingual content (Tamil/English) and modular feature cards. Core modules are calculation-driven and designed to expose precise tables and search interfaces to the user.
